> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Retire the eight surviving `*.module.css` files into Tailwind + `components/ui`, closing the 111 sub-3:1 dark-mode readings they cause, and leave behind a guard that makes the ninth impossible.

**Architecture:** One task per module, deletion before conversion where a module carries dead classes. A guard lands first, pinned red at today's 178 raw-token reads, and each module drives it down. Two existing tests (`css-module-fixed-widths.test.ts`, `orphan-stylesheets.test.ts`) enumerate these modules and must step down with them.

**Tech Stack:** Tailwind v4 (CSS-first, no config file), `components/ui/*` on Base UI, vitest (node env), Playwright MCP for the visual round.

**Spec:** `docs/superpowers/specs/2026-09-19-dark-mode-and-build-integrity-design.md` (§2.2, §6)

## Global Constraints

- Branch off `dev`: `feature/t033-css-modules`. Never push to `main`.
- **Requires PR0 merged.** Every contrast figure quoted in a commit or PR body must come from `lib/theme/contrast.ts`, which can only read the `.dark` oklch values after PR0.

- Colour comes from a bridge token — `bg-card`, `text-muted-foreground`, `border-border`. No `var(--color-*)`, no raw Tailwind palette class, no brand hex, and **no hand-written `dark:`**: a component that needs a `dark:` is bound to the wrong token. `components/ui/token-binding.test.ts` enforces this.
- `Button` has no `asChild`. A link styled as a button is `<Link className={cn(buttonVariants({ variant, size }))}>`.
- Every module task ends with: `pnpm sweep:overflow -- --filter=<route>` green, and Playwright screenshots at 320, 360, 390 and desktop in **both** themes. Await `document.fonts.ready` before measuring.
- `pnpm typecheck && pnpm lint && pnpm test` green before every commit. Never weaken a test to go green.
- Do not `git worktree add` in this repo. Establish a before/after baseline with `git show <sha>:<path>` or `git stash`.

### Task 1: The dark-safety guard, pinned red

**Files:**

**Interfaces:**

- [ ] **Step 1: Write the test**

Create `components/css-module-dark-safety.test.ts`:

```ts
import { readFileSync, readdirSync } from "node:fs";
import { join } from "node:path";
import { describe, expect, it } from "vitest";

/** Every `*.module.css` reachable from the product tree, found by walking rather than listed. */
function findModules(dir: string): string[] {
  return readdirSync(dir, { withFileTypes: true }).flatMap((entry) => {
    const path = join(dir, entry.name);
    if (entry.isDirectory()) return entry.name === "node_modules" ? [] : findModules(path);
    return entry.name.endsWith(".module.css") ? [path] : [];
  });
}

export const SURVIVING_MODULES: readonly string[] = [
  ...findModules("components"),
  ...findModules("app"),
].sort();

/**
 * Steps down as T-033 converts each module. The count is the POSITIVE CONTROL: without it, a
 * walk that found nothing would satisfy the raw-token assertion perfectly.
 */
const EXPECTED_MODULE_COUNT = 8;

/**
 * Raw Terra tokens are frozen at their light values — `.dark` redefines not one of the 13
 * these files use. Measured 2026-09-19 on /tr/turkiye/istanbul in dark: 111 of 181 text
 * elements carrying a module class fell below 3:1, worst 1.14:1 (`--color-ink` #2b2622 on
 * `--card` #121e21). Every read below is one of those failures waiting to render.
 */
const TOTAL_RAW_READS = 178;

describe("CSS modules cannot read a colour that dark mode never redefines", () => {
  it("found the modules it claims to check", () => {
    expect(SURVIVING_MODULES).toHaveLength(EXPECTED_MODULE_COUNT);
  });

  it("reads exactly the recorded number of raw Terra tokens", () => {
    const total = SURVIVING_MODULES.reduce(
      (sum, path) => sum + (readFileSync(path, "utf8").match(/var\(--color-/g) ?? []).length,
      0,
    );
    expect(total).toBe(TOTAL_RAW_READS);
  });

  it.each(SURVIVING_MODULES)("%s reads no raw Terra token", (path) => {
    const reads = readFileSync(path, "utf8").match(/var\(--color-[a-z0-9-]+/g) ?? [];
    expect(reads, `${path} reads ${reads.length}: ${[...new Set(reads)].join(", ")}`).toEqual([]);
  });
});
```
