# T-168 Homepage Search Box Accessibility Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The homepage hero search box gives the same keyboard and screen-reader behaviour as the
header box, and its placeholder reaches 4.5:1 in both themes.

**Architecture:** The header combobox's behaviour moves into shared pieces both boxes use:
`lib/search/combobox-keys.ts` (pure: which key does what), `lib/search/announcement.ts` (pure:
what the live region says) and `components/site-search/use-search-combobox.ts` (ids, active
option, debounced announcement, active-option scroll, input/listbox/option ARIA props). Each box
keeps its own markup: the header's command dialog, the hero's inline panel with icons and badges.

**Tech Stack:** React 19.2 client components, next-intl, vitest node env (`renderToStaticMarkup`
for the closed hero, pure functions for the rest), Playwright MCP for the open panel.

**Spec:** `/home/sertturk16/cografya_v4/TASKS.md` → T-168.

## Global Constraints

- ARIA 1.2 combobox + listbox: input `role="combobox"`, `aria-expanded`, `aria-controls`,
  `aria-autocomplete="list"`, `aria-activedescendant`; `role="listbox"` with `role="presentation"`
  `<li>` and `role="option"` `<a href tabIndex={-1} aria-selected>`; result count announced in a
  polite `role="status"` region on a 250 ms debounce, never "no results" while the index loads.
- Keys (both boxes): ArrowDown/ArrowUp wrap from "nothing selected", Home/End, Enter opens the
  active option or the first. Hero only: Escape closes its panel (the header's dialog owns Escape),
  ArrowDown opens a closed panel.
- Placeholder ≥4.5:1 measured in light and dark. No re-theme; use `text-muted-foreground`.
- No new copy.

## Review Focus

- Header behaviour unchanged after the refactor (its structure test stays green, browser check).
- Hero `aria-expanded` false while the panel is closed or shows no options.
- The count row and "Enter ile aç" hint sit outside the listbox (a listbox owns only options).
- Two comboboxes on the homepage get distinct ids (`useId`).
- Mouse hover still moves the highlight; click still opens with the toast.
